1. What advice would you give to yourself if you were to start a project like this again?

- Plan out the coding process, because it can save a ton of time and it would have made it easier for me to achieve my goal.

- Don't spend too much time on tutorial videos, just get the main idea and move on to the project as it can save tons of time.

- Create a detailed to do list, it will give you a concrete plan to work towards and save you from falling down the rabbit-hole.

- I would advice myself that keep the code neat and organized as it can be a whole lot of work to organize it.
